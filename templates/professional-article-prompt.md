# برومبت المقال الاحترافي — ركن التطور (مرجع تنفيذ)

استخدم هذا الملف كمعيار إلزامي عند كتابة أي مقال جديد أو إعادة كتابة مقال موجود لموقع `rukn-eltatawer.com/sa`.

## الهدف
مقال يتصدر Top 1–3 ويستهدف: البحث العادي + AI Overviews + Featured Snippets + Voice Search + Local SEO + E-E-A-T + التحويل.

## قواعد غير قابلة للتجاوز
1. HTML جاهز لـ WordPress
2. لا يقل عن **3500 كلمة فعلية** (بدون كود HTML)
3. H1 واحد فقط
4. **12 قسماً** H2 بمنطق SEO
5. أول 100–150 كلمة: Direct Answer معلوماتي قابل للاقتباس (بدون تسويق)
6. كل H2 معلوماتي يبدأ بإجابة مباشرة (AI Overviews)
7. 3–5 إجابات Featured Snippet (جملتان قابلتان للاقتباس)
8. 4–6 أحياء داخل المدينة
9. CTA عبر الشورت كود فقط — **ممنوع** إضافة أزرار اتصال/واتساب يدوية لأن `[post_call]` يحتويها
10. روابط داخلية ذكية + 5 روابط Cluster في النهاية
11. Shortcodes إلزامية داخل المحتوى: `[post_call] [post_prices] [post_features] [post_steps] [post_services] [post_gallery]`
12. **املأ محتوى كل البلوكات أسفل المقال** (الميتا) ثم استدعها بالشورت كود: المميزات، خطوات العمل، الخدمات، الأسعار، المعرض، شريحة الاتصال، الأسئلة الشائعة، المقتطف، الوسوم، Rank Math، وبلوكات السكيما
13. الصور من **مكتبة وسائط ووردبريس فقط** (`wp-image-ID` + رابط المصدر الحقيقي) + صورة بارزة
14. الجداول داخل Wrapper بـ `overflow-x:auto` لتناسب الموبايل
15. بلوكات بصرية: تنبيه خطر / نصيحة خبير / عرض خاص / إحصائية + E-E-A-T بعد H1
16. أيقونات Font Awesome بدل الإيموجي
17. ~60 فقرة، كل فقرة 50–60+ كلمة
